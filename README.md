## 🚀 Running Locally

```bash
# Option 1: Python HTTP Server (Built-in)
python -m http.server 3456

# Option 2: Node.js Serve
npx serve .

# Option 3: VS Code / Antigravity IDE Live Server extension
```

Navigate to `http://localhost:3456/` in any browser.
